# The Batman — Página de fã

Projeto de estudo de front-end inspirado no filme *The Batman*, de 2022. A página apresenta uma sinopse, o trailer local e uma seção com personagens, utilizando HTML e CSS.

## Funcionalidades

- Estrutura de página com HTML.
- Estilização personalizada com CSS e a fonte Kdam Thmor Pro.
- Vídeo local do trailer e imagem de logotipo.
- Cards do elenco e navegação entre seções.

## Como executar

Não é necessário instalar ferramentas de build. Clone o repositório e abra o arquivo `index.html` em um navegador.

## Arquivos do projeto

- `index.html` — estrutura e conteúdo da página.
- `style.css` — layout e identidade visual.
- `The Batman - Trailer Principal.mp4` — arquivo local do trailer.
- `log batman.jpg` — imagem do logotipo.

## Observações

Este é um projeto educacional de fã e não possui vínculo oficial com os detentores dos direitos do filme. A chamada para compra de ingresso foi substituída por um link para a seção do trailer.
