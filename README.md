# The Batman — Fan Landing Page

A front-end study project inspired by the 2022 film *The Batman*. The page presents a synopsis, a local trailer video, and a cast section using HTML and CSS.

## Features

- Responsive page structure built with HTML.
- Custom styling with CSS and the Kdam Thmor Pro typeface.
- Local trailer video and project logo.
- Cast cards and navigation between page sections.

## Run locally

No build tools are required. Clone the repository and open `index.html` in a browser.

## Project files

- `index.html` — page structure and content.
- `style.css` — layout and visual styling.
- `The Batman - Trailer Principal.mp4` — local trailer asset.
- `log batman.jpg` — logo asset.

## Notes

This is an educational fan project and is not affiliated with the film's rights holders. The purchase-ticket call to action has been replaced with navigation to the trailer section.
